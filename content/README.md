# 内容目录

- `base/`：一次导入生成的格式 3 中央资源库，Git 忽略。公共定义、全局脚本对白、地图事件、共享图像和来源缓存只存一份。
- `examples/`：独立编写的剧情示例，纳入版本控制。
- `mods/`：自行编写的 MOD 数据；当前通过显式剧情叠加加载，纳入版本控制。
- `imported/`：旧场景包本机留存，Git 忽略，仅兼容读取。

导入使用工程根目录的 `import.ps1`，默认输出 `base/`；场景编号只在加载或运行时选择，不逐场景导出。`run.ps1 -EventDemo` 在内存中应用 `examples/event-demo.json`，不复制基础资源。

原作输入目录保持只读，原版及解码资源不分发。具体结构见 [中央资源库](../docs/resource-library.md)。
