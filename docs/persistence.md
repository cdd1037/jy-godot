# 存读档与会话生命周期

侧栏提供三个存档槽，已有槽覆盖前确认。保存发生在稳定自由行动时：移动已经完成，没有对话、事件、战斗、商店、终端结局、切图或淡变。保存的是本次会话的运行变化，公共资源仍由同一个 `GameLibrary` 管理。

默认路径为 Godot `user://saves/`，Windows 通常位于 `%APPDATA%/Godot/app_userdata/金庸群侠传 · 重制/saves/`，以 Godot 实际解析路径为准。它不在原版目录、中央资源库或 Git 中。存档使用本项目格式 1，不兼容 DOS 的 RANGER/S/D 存档文件。

## 分层

`Game.Core.Persistence.SessionSnapshot` 只含核心数据，不做文件操作、不引用 Godot：当前场景与世界位置、朝向/船、人物全部运行字、队伍、物品使用者、背包及独立物品 ID 集、命名空间变量、已访问/修改场景的六层地图/事件/元数据、镜头/渐变，以及唯一执行器的 RNG、单调令牌和完成记录。定义与资产不写入快照；可写人物运行字段保留引擎的 32 位值，不重新压回 DOS 字长。

`GameSession.Restore` 完整校验并建立隔离候选，不修改正在玩的会话，不执行开场。脚本可能把玩家当前格改为阻挡，因此恢复验证坐标边界和场景身份，不把合法的原地阻挡当作无效出生点。世界模式另外保留最后本地图坐标，避免拿世界坐标当作本地图出生点。

本轮快照新增可选 `shop_stocks`（`SessionSnapshot.ShopStocks`），按商店 ID 保存各物理商品槽剩余库存。未出现该字段或为 null 表示商店接入前的检查点，采用当前定义初始库存；提供字段时必须匹配全部商店身份、槽数和合法库存范围。它不保存活动菜单、购买反馈页或 `PendingShop`，不能在交易中间存档。商品价格/初始库存仍来自库定义，不复制到快照。

`current_music_id` 与 `exit_music_override` 保存曲目选择及下一次离场覆盖；旧快照缺省为无当前曲目/-1。读取后宿主按恢复的曲目重新开始，不保存 MIDI 播放时间、Windows 设备句柄或音符队列。商店和音乐字段保持格式 1 的可选扩展，不意味着不同资源库指纹可绕过身份校验。

`Game.Content.Persistence` 负责文件与内容身份：

- `SaveGameDocument` 包装快照、UTC 时间、显示摘要、资源库指纹及实际剧情 overlay。overlay 内嵌，重启后不依赖原 JSON 路径；人物和地图定义仍引用中央库。
- `SaveGameIdentity` 重新校验已跟踪文件，再对规范化清单及来源哈希求身份摘要，不包含资源库绝对安装路径。字节相同的库搬动目录后仍可读档；重新导入后程序集合或数据改变，指纹改变，会明确拒绝旧档。当前没有版本迁移器。
- `SaveGameStore` 使用三个 JSON 文件，单文件最多 64 MiB；严格校验版本、字段、重复 JSON 属性和 SHA-256 封套。写入先落临时文件并刷盘，再原子替换，旧槽保留 `.backup.json`；不会自动把备份当作当前进度。校验和用于检测损坏，不证明内容可信。
- `SaveGameLoader` 校验身份，按 overlay 的入口场景组装程序定义，按快照的当前场景恢复。二者可以不同；最后为本地图或世界地图准备对应视图。

Godot 最后准备纹理并提交视图与会话。解析、内容身份、核心校验或纹理准备失败时继续保留旧游戏；提交成功后永久废弃旧执行器及调用栈，清理旧战斗界面和输入。

## 死亡与脚本载入

原版 15 和 24 分别转换为 `death` 与 `load_menu`，使用同一个事件执行器的终端 `PendingLifecycle`。15 的参数未被原机读取，不自动播放对白 83。两个菜单都只能读档或确认退出，不能取消后继续旧剧情。读档失败或拒绝退出时菜单保持，成功则换成新会话。

Godot 用不同底色区分死亡与普通载入，布局、按钮选择和过渡采用近似重制；没有复刻 `DEAD.BIG` 画面、原版按键怪异行为或多层淡变时序。机器依据见[指令兼容](original-opcode-coverage.md)，不把 UI 夹具视为真实剧情败战验收。

62 的 `PendingEnding` 同样是终端交接；结局动画/名单确认后结束宿主，不返回旧事件，也不把结局阶段写成可保存的自由状态。旧库需重新导入才能包含新增程序、规范化音乐与结局；导入后内容身份通常改变，当前没有把旧资源库存档自动迁移到新库的工具。可选 `ShopStocks` 的结构兼容与库身份兼容是两件事。

## 验证入口

```powershell
.\build.ps1
.\run.ps1 -Smoke -EventDemo -SaveSmoke -Headless -Report .local/verification/saves.json
```

存档冒烟在 `.local/` 使用全新隔离目录，不动玩家三个槽。它经过实际保存/载入按钮和覆盖确认，接任务保存、交付、拒绝损坏档、完整恢复后再交付并检查一次性奖励；另外向测试 overlay 加两条明确合成的生命周期命令，验证失败/取消退出不能逃离死亡或载入菜单、成功替换后不恢复旧剧情。普通 `-EventDemo` 不加入这两条夹具。

上述是既有验证入口与历史覆盖说明。本轮商店库存、音乐状态、结局终端及接线未重新导入，也未运行构建、测试或画面验证；旧存档通过记录不覆盖这些新增字段和流程。
