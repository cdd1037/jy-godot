# 正式菜单

第一阶段 UI 对齐：探索主菜单采用原版 `(20,18)` 小列表，系统页在 `(70,18)` 展开，队员列表在 `(68,18)`；这些坐标属于 320×200 逻辑画布，并随游戏视图等比缩放。使用现代中文字体、深灰半透明框、暖色普通字和浅色选中项，鼠标悬停/点击与键盘共用原控制器；右键打开探索菜单、在菜单内右键返回。正常游戏隐藏演示顶栏、页边距和圆角外框，调试信息仍可用 F3 展开。标题和现代附加系统项保留，背包、人物状态内容、商店、战斗和存档尚未逐页对齐原版排版。

对白使用同一逻辑分辨率：按原版 style0..5 放置独立的头像框与三行正文框，不显示现代姓名标题或大“继续”按钮；点击头像/正文继续，选择项支持悬停和点击，右键只取消允许取消的选择。字体继续使用现代字体，不转换 DOS 字库。位置依据只读 OpenLegend `BasicUiRenderer::render_game_menu_main/render_game_menu` 与 `SceneSession::render`，配色和透明度为可读性近似，不宣称像素复刻。

普通启动先显示标题页。载入资源时创建 `startInitialProgram:false` 的暂存会话，不运行或提前结算开场；选择“新的开始”后才创建实际游戏会话。新会话和纹理准备成功后提交替换，再废弃旧会话。测试阶段仍默认跳过开场，显式 `-PlayOpening` 正常播放；`-DirectPlay` 和冒烟入口可直接进入场景。

标题页提供新游戏、载入进度、准备原版资源、打开资源库、设置和退出。返回标题会保留当前游戏，可选择继续；重新开始与退出须确认。标题上的载入可直接使用暂存会话关联的资源库，不要求先开始新游戏。

稳定自由行动时按 Esc 或点击菜单按钮打开“医疗、解毒、物品、状态、离队、系统”。游戏菜单和行囊暂停宿主对世界时钟的推进，不改变核心 `CanSave`；剧情、移动、商店、战斗、死亡/载入和结局期间不能开启探索菜单。菜单关闭清除持有方向并设置同帧输入屏障。

医疗、解毒先选择施术者，再选择目标，结果来自 `GameSession.UsePartyAbility`，共享既有 `BattleSupportRules` 与唯一 RNG。探索选择要求对应技能至少 10；医疗使用原核心体力与疗效规则，不追加战斗行动结束的扣除；解毒不额外扣体力。零疗效仍是一次合法尝试。人物状态为只读格式化，不推进随机数。

离队通过原版固定角色表定位 950–998 的辞别脚本，交给当前事件执行器执行，不直接从界面移除角色。世界地图使用显式场景引用的原版程序，保留世界行走状态；需要隐式小场景上下文的 MOD 覆盖会被提前拒绝。剧情结束回到菜单；没有逐帧复刻 DOS 菜单尾部的淡变。

行囊由独立 `InventoryController` / `InventoryPanel` 负责，支持装备、服药、修炼和场景物品事件；修炼转移、自宫确认分步进行。显示模型只携带不透明身份标识，控制器检查会话、代次和所选物品/人物，拒绝旧控件。诊断改用面板只读控件接口，不依赖旧 AcceptDialog。

系统页复用三个存档槽，保存失败或载入失败停在原页，返回恢复父菜单；死亡和脚本载入菜单继续保持终端行为，Esc 不能返回旧剧情。设置包含背景音乐和平滑移动，保存到 `user://settings.cfg`，不进入游戏存档或资源库。平滑移动默认关闭，已保存的手动选择仍会保留。背景音乐开关控制宿主 MIDI 播放器。

场景预览、资源导入、碰撞辅助等开发控件默认收起，F3 显示调试侧栏；F1/F2 只在侧栏开启时处理。`run.ps1 -DebugTools` 可直接展示。正式标题保留准备资源入口，正常游玩不要求操作场景编号。

核心规则研究来源为只读 OpenLegend 的 `research/evidence/functions/Z_DAT/0x21496.md`、`0x21AC0.md`、`0x25BBA.md`、`0x39DA3.md` 与历史 `0x3A10C` 合同。菜单采用 Godot 控件与近似布局，不宣称 DOS 像素或时序一致。本轮未运行构建、测试、导入或画面验收；既有冒烟记录不验证这些新界面与迁移。
